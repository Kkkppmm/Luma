# Editor Guide

## Layout

1. **File tree** (left) — browse project files
2. **Source editor** (center) — GtkSourceView with highlighting
3. **Header** — Home, Save, and Tools menu

## Right-click tools

Right-click in the editor to use:

| Action | What it does |
|--------|----------------|
| Format Document | Normalize indentation and trim trailing whitespace |
| Format Selected Lines | Format only the selected lines |
| Indent Lines | Increase indent |
| Unindent Lines | Decrease indent |
| Trim Trailing Space | Remove end-of-line spaces |
| Sort Selected Lines | Sort selection alphabetically |
| Toggle Comment | Comment / uncomment with `//` |
| Save | Write the current file |

The same menu is available from the header Tools button.

## Shortcuts

- `Ctrl+S` — Save
- `Ctrl+Shift+F` — Format document
