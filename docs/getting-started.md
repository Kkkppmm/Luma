# Getting Started with Luma Builder

Welcome to **Luma Builder** — a lightweight IDE for GTK4 and libadwaita apps in C and C++.

## Home

- **New Project** — choose from **30+ starter templates** (GNOME, GTK, console, libraries, CMake, Python, Flatpak)
- **Recent Projects** — reopen past work
- **☰ menu** — SDK Manager, Check for Updates, Help, Docs, About
- **SDK Manager** card — download GNOME Platform / Sdk runtimes

## Editor

- File tree on the left — click a file to open it
- **Build** / **Run** in the header — meson compile (and launch) with a Build Log pane
- **Right-click** the code for Format, Indent, Trim, Sort Lines, Comment, and Save
- The same tools are in the header Tools (☰) menu

## Shortcuts

- `Ctrl+S` — Save
- `Ctrl+B` — Build project
- `F5` — Build & Run
- `Ctrl+Shift+F` — Format document
- `Ctrl+U` — Check for updates
- `F1` — Help
- `Ctrl+Q` — Quit

See also [updates.md](updates.md) for the GitHub auto-install flow and [templates.md](templates.md) for the full template list.
